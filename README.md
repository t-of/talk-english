# talk-english — 中学英文法・英単語1000・会話フレーズ

中学英文法、NGSL頻出1000語、日常会話のフレーズと熟語を学べる英語学習サイト

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/talk-english/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

中学英文法・NGSL 頻出 1000 語・会話フレーズと熟語・句動詞を、会話で早く使える順に **20 ユニット**（5 フェーズ）に組んだコース。
横長の画面では左にコース、右に本文。スマホでは下のタブで切り替える。進み具合は端末の中に保存される。

- **ユニット**: 1 ユニット＝文法 2 項目＋単語 50 語＋場面の会話フレーズ（か熟語）＋句動詞。
  ① 文法を理解（コア → 用法と例文 → 確認問題）→ ② 単語（一覧・カード・4 択）→ ③ フレーズ（日本語を見て言う・カード）→
  ④ 話す（文法の例文を日本語から英語に。🎤 で聞き取って一致した語を示す）→ ⑤ まとめテスト 10 問（8 問以上で修了）。
- **ホーム**: 次にやること、今日の復習、14 日の学習量、横に流れるロードマップ。
- **復習**: カード・テスト・話す練習で学んだ語句を、覚え具合に合わせて 1・2・4・7・15・30・60 日あとに出す（間隔反復）。
- **ライブラリ**: 全部の文法・単語・フレーズ・熟語・句動詞を検索して見る。
- 英文は ▶ で端末の音声で読み上げる。PC では Space / Enter / 1〜4 / R キーでも進められる。

文法・単語・句動詞のデータは [コアイメージ英語](https://t-of.github.io/core-image-english/) から流用し、構成はこのアプリで作り直した。

## データ

端末の外には何も送らない。localStorage の `talk-english.v2` に、語句ごとの復習の箱と次の日、ユニットの進み具合、文法の確認問題の最高点、日ごとの学習量を入れる（v1 の `talk-english.state` は初回に引き継ぐ）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
