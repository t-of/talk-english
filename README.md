# talk-english — 中学英文法・英単語1000・会話フレーズ

中学英文法、NGSL頻出1000語、日常会話のフレーズと熟語を学べる英語学習サイト

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/talk-english/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

下のタブで切り替える。進み具合は端末の中に保存される。

- **文法**: 中学英文法 40 項目を、学年順ではなく会話で早く使える順（7 ステップ）に並べた。各項目は「コア（どういう気持ちの形か）」→ 用法と例文 → 確認問題。
- **単語**: NGSL 頻度順の上位 1000 語を 50 語ずつ。一覧（発音記号・例文つき）、カード、4 択テスト。
- **フレーズ**: 場面別の会話フレーズ、よく使う熟語、句動詞。「英語をかくす」で日本語を見て言う練習、カードで日→英。
- **復習**: カードで「まだ」にしたもの、テストで間違えたものを集めて復習。
- 英文は ▶ で端末の音声で読み上げる。

文法・単語・句動詞のデータは [コアイメージ英語](https://t-of.github.io/core-image-english/) から流用した。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
